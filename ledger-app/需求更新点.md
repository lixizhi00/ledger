# 需求更新点（对照 需求.md 扫描）

## 一、本次更新项

### 1. 密码：使用 input 自带的 password 功能（需求 2.6.1 / 2.6.2 / 2.6.3）

- **需求原文**：密码默认密文展示，可以切换明文；**密码切换明文密文 用input框自带的 password 功能**。
- **实现**：使用 `type="password"` / `type="text"` 切换实现密文与明文，并保留点击切换控件（眼睛图标 👁），符合「自带的 password 功能」+ 可切换明文的描述。分类管理弹框 input 自动聚焦已满足。

### 2. 注册页：获取本机手机号（需求 2.6.1）

- **需求原文**：注册页面需支持「**获取本机手机号**」。
- **实现**：
  - **微信小程序**：在注册页手机号输入区域增加「获取本机手机号」按钮（`open-type="getPhoneNumber"`），用户授权后使用返回的 `code` 调后端接口兑换手机号并回填到输入框。
  - **后端**：新增 `POST /api/auth/wechat-phone`，请求体 `{ "code": "微信返回的 code" }`，使用微信接口兑换手机号后返回 `{ "phone": "13800138000" }`；未配置或非微信环境时返回明确错误，前端可提示用户手动输入。

## 二、已满足的需求（简要）

- 主页面：今年/本月/今日总支出及日期、右侧「>」、跳转账目列表并带筛选。
- 记账页：金额必填「请输入支出金额」、分类级联、时间/备注、完成提交。
- 预算页：月/年 Tab、一级/二级分类、年预算底部「编辑」「保存」、进度条与剩余额度。
- 分类页：一级/二级、拖动排序、删除确认、编辑/新增、弹框 input 自动聚焦。
- 账目列表：按来源筛选（今日/本月/今年/预算二级分类）。
- 登录/注册/忘记密码：账号密码、密文切换、忘记密码入口与重置密码页及 API。

## 三、本次已实现

1. **注册页**：微信环境下展示「获取本机手机号」按钮，授权后调用后端兑换手机号并回填；非微信或未配置时仍可手动输入。
2. **后端**：`POST /api/auth/wechat-phone`，可选配置 `app.wechat.appid` / `app.wechat.secret`，未配置时返回 400 提示「请手动输入手机号」。
