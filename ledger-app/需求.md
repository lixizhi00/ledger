
# Ledger App 需求文档

## 文档说明

本文档为基于uniapp开发的记账类App需求说明，目标是一套代码同时生成微信小程序和iOS App，所有需求点按结构化、标准化方式呈现，确保AI能精准理解功能逻辑、数据关联、交互规则。

## 一、核心开发基础

1. 技术框架：uniapp（一套代码适配微信小程序、iOS App）
2. 核心数据维度：支出记录（金额、分类、时间、备注）、预算（年/月维度，一级分类/二级分类维度）、预算余额（月度剩余、跨月累计）

## 二、页面功能需求

### 2.1 主页面

#### 2.1.1 数据展示

| 展示项 | 数据逻辑 | 附加要求 |
|--------|----------|----------|

| 今年到今日总支出 | 统计当前自然年1月1日至今日的所有支出总和 | 展示对应日期范围（如“2026年1月1日-2026年2月25日”），右侧添加“>”图标（可点击） |
| 本月总支出 | 统计当前自然月1日至今日的所有支出总和 | 展示对应日期（如“2026年2月”），右侧添加“>”图标（可点击） |
| 今日总支出 | 统计当天00:00-当前时间的所有支出总和 | 展示对应日期（如“2026年2月25日”），右侧添加“>”图标（可点击） |

#### 2.1.2 交互规则

- 点击“今年到今日总支出”“本月总支出”“今日总支出”任一区域（含“>”图标），均跳转至**账目列表页**，列表默认筛选对应时间范围的所有支出记录。
- 页面下方展示3个便捷入口按钮：预算、记账、分类，点击分别跳转至对应页面。

### 2.2 记账页面

#### 2.2.1 表单元素

| 元素 | 功能逻辑 | 交互规则 |
|------|----------|----------|

| 金额输入框 | 接收用户输入的支出金额（数字型，支持小数点后两位） | 必填项，无输入时点击完成按钮需提示“请输入支出金额” |
| 分类选择器 | 仅展示二级分类，展示格式为“一级分类名称>二级分类名称” | 必填项，默认无选中状态，点击后弹出分类选择弹窗（仅显示二级分类，按一级分类分组）弹框用级联选择器展示 |
| 时间选择器 | 默认选中当前系统时间（精确到天） | 支持用户修改为历史时间，格式为“YYYY-MM-DD” |
| 备注输入框 | 接收用户输入的支出备注信息 | 选填项，无字符长度限制 |
| 完成按钮 | 提交记账信息 | 点击后校验金额、分类是否填写，校验通过则保存支出记录并返回主页面；校验失败则提示对应错误信息 |

### 2.3 预算页面

#### 2.3.1 页面结构

- 顶部包含2个Tab：月预算、年预算，默认展示月预算Tab。
- 所有预算展示均按“一级分类-二级分类”层级呈现，二级分类隶属于对应一级分类下。

#### 2.3.2 月预算Tab

##### 2.3.2.1 核心规则

1. 预算额度计算：
   - 二级分类月预算额度 = 该二级分类年预算额度 / 12 + 前序所有月份该二级分类剩余预算额度（1月剩余加至2月，2月剩余加至3月，依此类推；若前序月份超支，则从当月额度中扣除）。
   - 一级分类月预算额度 = 其下所有二级分类月预算额度之和（自动计算，不可手动编辑）。
   - 月度总预算额度 = 所有一级分类月预算额度之和（自动计算，不可手动编辑）。
2. 数据展示（按“月度总预算-一级分类-二级分类”层级）：

   | 展示层级 | 展示内容 | 交互规则 |
   |----------|----------|----------|
   | 月度总预算 | ① 当月总预算额度（含前序月份余额/扣减）；② 本月总支出金额；③ 剩余预算额度（预算-支出，超支则显示负数）；④ 进度条（支出/预算，超支则进度条满格并标红） | - |
   | 一级分类 | ① 一级分类名称；② 该分类当月预算额度（下属二级分类之和）；③ 该分类本月总支出；④ 剩余预算额度；⑤ 进度条（支出/预算） | - |
   | 二级分类 | ① 二级分类名称（格式：一级分类名称>二级分类名称）；② 该分类当月预算额度（含前序月份余额/扣减）；③ 该分类本月总支出；④ 剩余预算额度；⑤ 进度条（支出/预算）；⑥ 右侧“>”图标 | 点击“>”图标跳转至账目列表页，筛选条件为“今年+该二级分类”的所有支出记录 |

#### 2.3.3 年预算Tab

##### 2.3.3.1 核心规则

1. 预算额度编辑：
   - 仅可手动编辑**二级分类年预算额度**，一级分类年预算额度 = 其下所有二级分类年预算额度之和（自动计算，不可编辑）。
   - 年度总预算额度 = 所有一级分类年预算额度之和（自动计算，不可编辑）。

2. 功能按钮

  - 编辑按钮：点击之后可以编辑二级分类预算 只有一个总编辑按钮 放在底部 常在
  - 保存按钮：点击之后保存当前预算并同步调整月预算，放在底部 常在

3. 数据展示（按“年度总预算-一级分类-二级分类”层级）：

   | 展示层级 | 展示内容 | 交互规则 |
   |----------|----------|----------|
   | 年度总预算 | ① 本年总预算额度；② 今年到今日总支出金额；③ 剩余预算额度（预算-支出，超支则显示负数）；④ 进度条（支出/预算，超支则进度条满格并标红） | - |
   | 一级分类 | ① 一级分类名称；② 该分类年预算额度（下属二级分类之和）；③ 该分类今年到今日总支出；④ 剩余预算额度；⑤ 进度条（支出/预算） | - |
   | 二级分类 | ① 二级分类名称（格式：一级分类名称>二级分类名称）；② 该分类年预算额度（可编辑）；③ 该分类今年到今日总支出；④ 剩余预算额度；⑤ 进度条（支出/预算）；⑥ 编辑按钮 | 点击编辑按钮可修改该二级分类年预算额度，修改后自动更新对应一级分类年预算、年度总预算 |

### 2.4 分类管理页面

#### 2.4.1 页面结构

- 展示“一级分类-二级分类”层级结构，每个一级分类下展示其下属二级分类列表。

#### 2.4.2 功能按钮

- 添加按钮：支持添加一级分类、添加二级分类（需选择所属一级分类）。
- 保存按钮：保存所有分类的新增/修改/删除/排序操作。

#### 2.4.3 交互规则

1. 排序：二级分类支持**拖动排序**（手动调整同一一级分类下二级分类的展示顺序）。
2. 删除：一级分类、二级分类均有删除按钮，删除一级分类时需提示“删除后该分类下所有二级分类也将删除，是否确认？”，删除二级分类直接提示“是否确认删除该分类？”。
3. 编辑：支持修改一级分类、二级分类的名称。
4、创建一级分类/二级分类一级编辑分类名称弹框弹出时，input框自动聚焦

### 2.5 账目列表页

#### 2.5.1 数据展示

- 列表项包含：支出时间（YYYY-MM-DD）、支出金额、分类（格式：一级分类名称>二级分类名称）、备注。

#### 2.5.2 筛选规则

- 跳转来源不同，默认筛选条件不同：
  1. 从主页面“今日总支出”跳转：筛选“当天”的所有支出记录。
  2. 从主页面“本月总支出”跳转：筛选“本月”的所有支出记录。
  3. 从主页面“今年到今日总支出”跳转：筛选“今年到今日”的所有支出记录。
  4. 从预算页面二级分类跳转：筛选“今年+该二级分类”的所有支出记录。

### 2.6 登录/注册页面

#### 2.6.1 注册页面

- 获取本机手机号
- 输入账户名
- 输入密码 密码默认密文展示，可以切换明文
- 输入确认密码 密码默认密文展示，可以切换明文
-注册按钮： 点击注册成功 进入登录页
- 密码切换明文密文 用input框自带的 password 功能

#### 2.6.2 登录页面

- 账号：可以输入手机号和账户名
- 密码： 6位以上 数字/字母/字符 三选二 密码默认密文展示，可以切换明文
- 登录按钮： 进入主页
- 去注册按钮： 点击进入注册页面
- 忘记密码按钮： 点击进入忘记密码页面
- 密码切换明文密文 用input框自带的 password 功能

#### 2.6.3 忘记密码页面

- 输入新密码 密码默认密文展示，可以切换明文
- 输入确认新密码 密码默认密文展示，可以切换明文
- 保存按钮： 点击 保存成功跳转到登录页面
- 密码切换明文密文 用input框自带的 password 功能


## 三、数据关联核心规则（AI重点关注）

1. 预算联动规则：
   - 编辑二级分类年预算额度 → 自动计算对应一级分类年预算 → 自动计算年度总预算 → 自动计算该二级分类月预算（年预算/12）→ 自动计算对应一级分类月预算 → 自动计算月度总预算。
   - 月度预算余额跨月累计：1月二级分类剩余预算 → 叠加至2月该二级分类月预算；1月超支 → 从2月该二级分类月预算中扣除。
2. 分类数据联动：
   - 分类管理页面新增/删除/修改分类 → 记账页面分类选择器同步更新 → 预算页面分类层级同步更新 → 账目列表页分类展示同步更新。
3. 支出记录联动：
   - 新增支出记录 → 主页面各维度支出金额更新 → 预算页面对应维度（日/月/年、一级/二级分类）的支出、剩余预算、进度条同步更新。

### 总结

1. 核心架构：基于uniapp开发，覆盖主页面、记账页、预算页、分类管理页、账目列表页5大核心页面，核心数据为支出记录和预算数据。
2. 关键联动规则：年预算是基础（仅二级分类可编辑），月预算由年预算推导+跨月余额累计；一级分类预算为下属二级分类之和，不可手动编辑；分类操作需同步至所有关联页面。
3. 交互核心：所有可跳转区域均添加“>”图标，账目列表页需根据跳转来源自动筛选对应数据，预算页面需展示多维度进度条和剩余额度。
